# Reference

The guide covers how to run freetvarr and use each tab. This section is the companion for how it works underneath, and why.

Most of it lives in one place:

- **[Technical deep dive](/deep-dive)**: architecture, the TVHeadend API surface, the import state machine, the ad-removal pipeline, the live-progress registry, the mobile layout, the full environment reference, the Docker deployment model, the security model, and local development.

The deep dive is a single long page with its own contents list; the right-hand outline follows along as you scroll. If you're after a specific mechanism (why an import lands as `partial`, how keep-segments are computed for a cut, how a series becomes an autorec rule), start there.

For the source itself, see the [repository on GitHub](https://github.com/furey/freetvarr).
