# Reference

The guide covers how to run Freetvarr and use each tab. This section covers how it works underneath, and why.

- **[Technical deep dive](/deep-dive)**: architecture, the TVHeadend API surface, the import state machine, the ad-removal pipeline, the live-progress registry, the mobile layout, the full environment reference, the Docker deployment model, the security model, and local development.

The deep dive is one long page with its own contents list. Start there for a specific mechanism (why an import ends as `partial`, how keep-segments are computed for a cut, how a series becomes an autorec rule).

For the source itself, see the [repository on GitHub](https://github.com/furey/freetvarr).
